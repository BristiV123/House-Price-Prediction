# House Price Prediction

## Project Overview

This project predicts house prices using Machine Learning (Linear Regression).

## Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn

## Dataset

The project uses the `house_data.csv` dataset.

## Features

* Area
* Bedrooms
* Bathrooms
* Parking

## Target

* Price

## Machine Learning Model

Linear Regression

## Result

The model predicts house prices based on the given house features.
